# Зелёная Живопись — интернет-магазин растений

Full-stack интернет-магазин комнатных растений и товаров для них: каталог с фильтрами, корзина, избранное, личный кабинет покупателя и админ-панель для управления заказами, скидками и заявками.

## Возможности

**Для покупателя**
- Каталог в 4 разделах: растения, кашпо, товары для ухода, удобрения
- Фильтры по категории, освещению, сложности ухода; товары со скидкой
- Карточка товара, избранное, корзина и оформление заказа
- Регистрация и вход, личный кабинет с редактированием профиля и историей заказов
- Раздел статей по уходу за растениями
- Страница контактов с формой обратной связи

**Для администратора**
- Просмотр всех заказов и смена их статуса
- Управление ценами и скидками на товары
- Работа с заявками из формы обратной связи
- Аналитика по заказам

## Стек

| Часть | Технологии |
|---|---|
| Frontend | React 19, React Router 7, Vite, CSS |
| Backend | Node.js, Express 5 |
| База данных | PostgreSQL (`pg`) |
| Безопасность | Хэширование паролей через bcrypt, CORS |

## Архитектура

```
green-paint-shop/
├── src/                 # React-приложение
│   ├── App.jsx          # маршрутизация и общее состояние (корзина, избранное, пользователь)
│   ├── Catalog.jsx ...  # каталоги по категориям + модальные окна фильтров
│   ├── CartPage.jsx     # корзина и оформление заказа
│   ├── Profile.jsx      # личный кабинет
│   ├── AdminPanel.jsx   # админ-панель
│   └── data/products.js # локальный каталог товаров
├── public/images/       # изображения товаров и иконки
└── backend/
    └── index.js         # REST API на Express
```

Каталог товаров хранится на фронтенде (`src/data/products.js`), а в PostgreSQL — пользователи, заказы, заявки и настройки цен/скидок (`product_settings`). Актуальные цены и скидки подтягиваются с сервера и накладываются на локальный каталог.

## REST API

| Метод | Эндпоинт | Описание |
|---|---|---|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET / PUT | `/api/users/:userId/profile` | Профиль пользователя |
| GET | `/api/users/:userId/orders` | Заказы пользователя |
| POST / GET | `/api/orders` | Создание / список заказов |
| PUT | `/api/orders/:orderId/status` | Смена статуса заказа |
| GET | `/api/products/prices` | Цены и скидки |
| PUT | `/api/products/:id` | Изменение цены / скидки |
| POST / GET / DELETE | `/api/contacts-requests` | Заявки обратной связи |
| GET | `/api/analytics` | Аналитика для админ-панели |
