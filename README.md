Фуллстак-приложение для автоматизации продаж комнатных растений, дизайнерских кашпо и сопутствующих товаров для ухода. Разработано в рамках учебной практики УП.09.01.

Ключевые фичи проекта:
Динамическая панель администратора: управление заказами, inline-изменение розничных цен и дисконтных программ со стопроцентным runtime-сохранением.

Многокритериальная интерактивная фильтрация: сегментация каталога по стоимости, ботаническим категориям, уровню освещения и сложности ухода.

Личный кабинет клиента: модуль сквозного отслеживания статуса логистики заказов, баланс бонусных баллов и карусель «Избранное».

Двухуровневая валидация: встроенный контроль заполнения форм и проверка синтаксиса Email на стороне клиента и Express-сервера.

Архитектурный стек:
Frontend: ReactJS, Axios, React Router DOM v6, Vite.
Backend: Node.js, Express.
СУБД: PostgreSQL 18, pgAdmin 4.
