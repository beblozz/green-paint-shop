# Интернет-магазин комнатных растений «Зелёная Живопись»

Данный проект представляет собой адаптивное веб-приложение интернет-магазина, разработанное в рамках выполнения учебной практики УП.09.01.

## Технологический стек
* **Frontend:** ReactJS, React Router DOM (v6), Axios, CSS3, HTML5
* **Сборщик проекта:** Vite

## Функционал приложения
* Локальная архитектура хранения данных номенклатуры (48 активных позиций).
* Полноценная фильтрация товаров по 4 вкладкам (Растения, Кашпо, Уход, Удобрения).
* Динамическая панель администратора с возможностью локального изменения цен и скидок в режиме реального времени.
* Полноценная корзина с расчётом стоимости и личный кабинет пользователя.

## Инструкция по запуску проекта

Для запуска клиентской части выполните следующие команды в терминале:

```bash
# 1. Переход в директорию проекта
cd green-paint

# 2. Установка необходимых зависимостей
npm install

# 3. Запуск локального сервера разработки Vite
npm run dev
